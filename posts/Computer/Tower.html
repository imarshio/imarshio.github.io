主机，主要由以下几个关键组件组成

中央处理器（CPU）

作为计算机的大脑，CPU负责解释和执行程序指令，处理数据。

目前CPU厂商中，首推Intel，其次AMD。

可能有些人，包括我自己对芯片的各个参数等不是很了解，接下来我会给大家以我的视角进行略微的解读，算是我的学习过程。

Intel

以 i9 14900k 举例

i9，代表修饰符，值越大，越高端也越贵，产品编号相同的情况下，i3 < i5 < i7 < i9。

i3：入门

i5：中端

i7：高端

i9：旗舰

14900，代表产品编号，由代次指示符和SKU数值两部分组成，如14900中的14表示的就是14代CPU，后面的数值越大，性能越高。

k，代表该CPU的不同特性和功能。

核和线程的区别是什么？

核是物理层的概念，简单来说就是，有几个核就是有几个物理意义上的核，一比一的。

线程是逻辑层的概念，在早期，一个核心对应一个线程，但是现在我们知道，CPU分大小核，大核（Performance-core）相当于两个线程，小核（Efficient-core）相当于一个线程。

频率是什么？

CPU的频率，是指CPU在一秒钟内，可以执行的指令次数，这个次数越多越好。

1KHz=103Hz1KHz = 10^3 Hz 1KHz=103Hz

1MHz=103KHz1MHz = 10^3 KHz 1MHz=103KHz

1GHz=103MHz1GHz = 10^3 MHz 1GHz=103MHz

2GHz=2,000,000,000Hz2GHz = 2,000,000,000 Hz 2GHz=2,000,000,000Hz

超频是什么？

简单理解就是让电脑超水平发挥。

主板（Motherboard）

所有组件连接的平台，负责数据传输和电源分配，还决定了你的电脑的扩展性。

选择主板的前提就是先确定自己的目标CPU，然后根据CPU的插槽接口数量来确定主板。

这里我以14900KF举例，在这页面我们可以看到关于这个CPU的各种参数，其中有一项是Sockets Supported : FCLGA1700，这代表这款CPU支持的插槽接口类型为FCLGA1700，所以不支持FCLGA1700接口的主板，这里我就暂时不考虑了，Intel自12代之后就支持FCLGA1700接口了。

在选择主板时，我们一般会看CPU插槽接口、板型、供电、内存频率、扩展性，按需选择，满足自己的需求即可，除了一线品牌对主板有很大的加持，其他方面的差距可忽略不计。

跟CPU一样，主板的厂商也很多，但是一线厂商就三家：华硕、微星、技嘉。

图形处理单元（GPU）

可要可不要，取决于你的CPU是否自带核显，如不带核显，则需要，否则不一定需要。

如果你是办公或轻度游戏（不包括3A），买带核显的CPU即可，目前新的CPU自带的核显性能以能够满足大多数人对游戏的需求了，如果你是游戏玩家，则需要在这一方面好好选择。

对于需要图形处理的任务，如游戏和视频编辑，GPU可以分担CPU的负担。
