## Introduction

### Java是什么？

Java是一种面向对象的高级编程语言。

有一些人（当然，也包括我自己）可能会问什么是高级程序设计语言？

这就不得不说一下计算机语言的两大阵营：低级语言与高级语言，有关其详细信息可以参考[计算机语言](../Base/Term.md#计算机语言)。

### 面向对象编程特性

- 封装
- 继承
- 多态
  - 重写
  - 重载

### Java的基础数据类型

- byte
- short
- int
- long
- float
- double
- boolean
- char
