## 下载与安装

SDK：(Software Development Kit，软件开发工具包)。

下载地址：<https://golang.google.cn/dl/>

### Windows

推荐：下载 msi 安装包，这能省去我们配置环境变量的步骤，且不会出错。

下载完成后，打开 cmd 窗口，输入如下指令

```sh
C:\Users\demo>go version
go version go1.22.3 windows/amd64
# 出现如上说明已经配置好Go的环境，
```
