## 双指针

> 双指针算法是一种高效的遍历技术，它通过在数据结构中设置两个指针来解决特定的问题。这两个指针可以以不同的速度移动，或者从数据结构的不同位置开始，以实现快速的数据处理。例如，在排序数组中查找目标值时，可以使用两个指针分别指向数组的两端，通过逐步向中间靠拢来缩小搜索范围。在数组去重的场景中，一个指针用于遍历数组，而另一个指针则用于记录去重后的结果。这种算法的优势在于它能够减少不必要的比较和操作，从而提高算法的效率。双指针技术广泛应用于各种算法问题中，如滑动窗口问题、两数之和问题、循环链表检测等，是算法设计中的一种重要工具。
